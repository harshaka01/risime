# RisiMe v0.2.0-nightly.4

Fix release. Wire protocol: `contract/v1/PROTOCOL.md` **v1.4**. Server URL:
https://risime.risicloud.ai.

## Fixed
- **Crash when Keycloak returned to the app after sign-in.** AppAuth's redirect activity inherited
  our non-AppCompat theme and crashed on launch. It now has its own AppCompat theme.
- **Latent crash of the fingerprint dialog on Android 8–9.** On those versions, biometric's dialog
  needs an AppCompat theme. `Theme.RisiMe` now extends `Theme.AppCompat.DayNight.NoActionBar`.
- **Regression test** `MergedManifestThemeTest` reads the real merged debug and release
  manifests and fails if any activity resolves to a non-AppCompat theme. It failed before the fix
  and passes after.

## Server
No server code change. The pilot has run with **RisiCloud sign-in enabled** (`OIDC_ENABLED=true`,
Keycloak realm `aoa`, client `risime`) since 2026-10-06. Server output is also written to
`~/risime-logs/server.log`.

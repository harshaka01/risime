# RisiMe v0.2.0-nightly.24 — calls stay visible in the background, invite limits

Wire protocol: `contract/v1/PROTOCOL.md` v1.16. Server: https://risime.risicloud.ai. **Not a
required update.**

## Important: update, never uninstall
Always update **over** the old app. Never uninstall or clear the app's data.

## Fixed
- **A call seemed to disappear after pressing Home.** The call was still running, but it was hard
  to find. Now:
  - a green **"Call in progress — tap to return"** bar shows over the chats;
  - the call screen stays in Recents;
  - the ongoing-call notification is visible at once, also on the lock screen, with **Hang up**.
- **The caller hears a ringback tone** while the other phone rings.
- **Invites:**
  - up to 20 per person per day (was 10);
  - re-inviting the same phone number returns the same invite and doesn't count again;
  - failed attempts never count.

## Also live since nightly.23 (server)
- **Calls across networks:** the relay server (TURN) is live, so calls can connect between Wi-Fi
  and mobile data.

## Verification
- Gates: server (493 tests), Android.
- Real calls on Redroid: A presses Home and the screen goes off for 60 s; the call keeps going with
  audio both ways; the notification reopens the call; Hang up in the shade ends it on both phones.
- Live interop: all checks.
- Automatic two-phone upgrade gate on spark2 (Redroid): the published nightly.23 is upgraded in
  place to this build.

# RisiMe 0.3.0-nightly.8

- Risi now writes out voice notes in Official chats, in Sinhala, Tamil and English.
- Official chats now say "Encrypted · Risi can read", so it's clear Risi is part of them.
- The Risi skills page now explains each skill in one plain sentence.

## Fixed
- Your morning brief now shows in full inside the Risi chat, not just the open items.
- Messages waiting for encryption are now kept in backups and sent after a restore.
- Tamil voice notes are no longer written in Sinhala letters.
- Risi no longer asks you to type when it can't listen right away; it replies as soon as it can.
- Risi no longer says a phone permission is off when your phone has it on.

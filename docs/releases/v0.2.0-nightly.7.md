# RisiMe v0.2.0-nightly.7 — the E2EE-capable app

Wire protocol: `contract/v1/PROTOCOL.md` **v1.7**. Server: https://risime.risicloud.ai. **No
user-visible change yet:** E2EE stays switched off on the pilot until the rollout is approved.

## New
- **The app now carries the MLS crypto core** for all four Android ABIs (64- and 32-bit), with
  the real E2EE engine. It activates only when the server serves attestation keys, which the
  pilot doesn't yet. This is the build the required update will move everyone to at rollout.
  - The release APK grows from 12.7 MB to 19.9 MB (the native libraries are compressed).
- The membership executor (adding and removing devices), key-package top-up, and real-crypto
  tests.

## Verification
- **Gates:** server 265 tests, Android 162 tests (debug and release builds), crypto 47 tests.
- **Live interop: 32 checks, all passing.** That includes, for the first time, **9 end-to-end
  encryption checks with real MLS** against a real server with E2EE switched on (temporary key):
  - the server's attestation verifies inside the Rust core;
  - group creation and joining via Welcome;
  - messages encrypted both ways, with no stored message carrying a body;
  - `e2ee_required` and the stale-epoch retry;
  - concurrent device adds converge after exactly one conflict;
  - a removed device can't decrypt;
  - a legacy app keeps a conversation not ready.

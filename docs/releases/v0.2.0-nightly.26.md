# RisiMe v0.2.0-nightly.26 — lost chats come back by themselves

Wire protocol: `contract/v1/PROTOCOL.md` v1.16. Server: https://risime.risicloud.ai. **Not a
required update.**

## Important: update OVER the old app — never uninstall
Updating never deletes your chats. **Uninstalling, or "Clear storage" in Android settings, does**:
your phone becomes a new device. Always install the new version over the old one (Settings →
Update, or the APK from https://risicloud.ai/app/risime/ over the existing app).

## What happened with "nightly.25 wiped my chats"
- The update didn't do it. On the affected phone the app's data had been removed by Android
  (an uninstall + reinstall, or Clear storage). That shows as a new device id: the device id is
  created only on first run and the app never deletes it.
- A real update keeps everything: nightly.24 → nightly.25 kept the device id and every message in
  the upgrade gate.

## Fixed
- **Lost history now comes back by itself.**
  - After a reinstall, messages the server still has (the last 30 days, including your own sent
    ones) are restored.
  - Encrypted history is requested **automatically** from your other phone (it asks you once to
    allow that phone) or, in groups, from a member, who is asked first.
  - Before, nothing happened until someone tapped "Request history".

## Verification
- Gates: server, Android (including the automatic history request).
- Live interop: all checks.
- **Stronger automatic upgrade gate** (two Redroid phones). It counts messages per chat (1:1,
  groups, photos, call records) before the update, then requires the same or more after the update
  *and* after a log out + sign in. Any loss blocks the release (new hard rule, decision 055).

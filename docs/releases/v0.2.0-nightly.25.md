# RisiMe v0.2.0-nightly.25 — hotfix: dark screen after a call

Wire protocol: `contract/v1/PROTOCOL.md` v1.16. Server: https://risime.risicloud.ai. **Not a
required update.**

## Important: update, never uninstall
Always update **over** the old app. Never uninstall or clear the app's data.

## Fixed
- **A dark, empty screen could stay after a call:**
  - When a call ends, the call screen now always closes and you're back in the chat.
  - A stale call notification or Recents card no longer opens an empty call screen.
  - Back during a call returns to the chat, and the call keeps going (the green "Call in progress"
    bar brings you back).
- **Closing the call screen no longer hangs up the call.** Only swiping RisiMe itself away does.

    lands on a call screen;
  - hanging up returns to the chat;
  - no leftover call or audio mode.
- Live interop: all checks.

# RisiMe v0.2.0-nightly.21 — hotfix: messages stuck on the clock icon

Wire protocol: `contract/v1/PROTOCOL.md` v1.15. Server: https://risime.risicloud.ai. **Not a
required update.**

## Important: update, never uninstall
Always update **over** the old app. Never uninstall or clear the app's data.

## Fixed
- **Messages stayed on the clock icon in every chat:**
  - When one encrypted chat couldn't send yet (for example its encryption wasn't ready), the app
    stopped sending *all* messages behind it, in all chats.
  - Now only that chat waits; every other chat sends at once.
  - If a message still can't be sent after 30 seconds, it shows "Not sent — encryption with this
    chat isn't ready. Tap to retry" instead of waiting silently.
  - Messages already stuck are sent with their original ids after the update (no duplicates).

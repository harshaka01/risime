# RisiMe v0.2.0-nightly.3

Nightly build from `main`. Wire protocol: `contract/v1/PROTOCOL.md` **v1.4**. This is the first
build served as the **public pilot** at **https://risime.risicloud.ai** (decision 023).

## New
- **Public pilot:**
  - The server runs as a **prod-mode release** behind Caddy on spark2 (automatic HTTPS). Phoenix
    is on 127.0.0.1 only.
  - There are no dev routes, no debug pages, no Erlang distribution, and `check_origin` is limited
    to the pilot origin.
  - The release app's default server is `https://risime.risicloud.ai`. Installs that still had the
    old `https://risicloud.ai/risime` default move over automatically.
- **One-time SMS phone verification** (contract v1.4), **off on the pilot** until the "RisiMe"
  sender ID is approved by Notify.lk:
  - the server gate (`PHONE_VERIFICATION`), hashed codes, rate limits counted in Postgres, and the
    NotifyDEMO guard;
  - the app's "Confirm your phone" screen.
- **Abuse controls:**
  - per-IP limits on `/auth/request` (10 per 15 min) and `/auth/verify` (20 per 15 min);
  - one plain auth-failure line per event in `~/risime-logs/auth.log`, for fail2ban (jail in
    `infra/fail2ban/`).
- Dev login stays available until Keycloak is live. Codes appear only in the server log.

# RisiMe v0.2.0-nightly.23 — hotfix: calls had sound in one direction only

Wire protocol: `contract/v1/PROTOCOL.md` v1.16. Server: https://risime.risicloud.ai. **Not a
required update.**

## Important: update, never uninstall
Always update **over** the old app. Never uninstall or clear the app's data.

## Fixed
- **On calls, only the caller could be heard** (since nightly.16). The answering phone never sent
  its microphone. Now both directions carry sound.
- **Both phones need this version:** a phone on nightly.22 or older still can't be heard when it
  answers.

## Verification
- Gates: server, Android.
- Real calls on Redroid (arm64): the bug was reproduced first (caller sent 1854 bytes, received 0).
  With the fix, 5 calls had audio both ways, including one answered from the notification while
  the app was in the background. The call test now fails unless both phones send and receive
  audio.
- Live interop: all checks.
- Automatic two-phone upgrade gate on spark2 (Redroid): the published nightly.22 is upgraded in
  place to this build.

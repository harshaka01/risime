# RisiMe v0.2.0-nightly.1

Nightly build from `main` (night 1 of the 0.2 cycle). Wire protocol: `contract/v1/PROTOCOL.md`
**v1.2**. This is the first **release-signed** APK (dev key, `docs/decisions/003`).

## New for users
- **Presence and last seen:** a green dot when someone has the app open; "last seen …" otherwise
  (5 s grace before going offline).
- **Typing indicator:** "typing…" in the chat header and on the Chats row.
- **Settings:** server URL (in every build; the login screen has a "Server · Change" link too),
  display name, app and protocol version, and log out.
- **Chat polish:**
  - unread badges with bold unread chats;
  - day separators;
  - long-press → Copy;
  - Retry / Delete for messages the server rejected;
  - Search across people and messages.
- **Design system:**
  - light and dark tokens and shared components;
  - text contrast of at least 4.5:1, enforced by a test;
  - touch targets of at least 48 dp, and TalkBack labels.
  - In light mode the read tick is now darker saffron (`#9C5F00`) for contrast.
- The "Dev build — not end-to-end encrypted" banner is unchanged.

## Server and ops
- Contract v1.2 (additive): `presence:watch`, `typing`, and the ephemeral `signal` push.
- Oban (Postgres) with daily jobs that prune old OTP challenges and revoked tokens.
- Observability:
  - JSON logs (`LOG_FORMAT=json`, the default in prod) with sensitive params filtered;
  - telemetry metrics for sends, acks, connects and joins;
  - `GET /health`.
- Load test, `mix risime.loadtest`:
  - 200 users at about 200 msg/s: 0 errors, reply p50/p95/p99 4.3 / 5.6 / 6.3 ms.
  - 2000 users at about 3200 msg/s: 0 errors, reply p99 45 ms.
  - It led to two fixes: a larger Cassandra pool with a brief retry when it's full, and one pool
    checkout per query instead of two.
  - Details: `docs/status/loadtest.md`.
- Prod preparation, not deployed:
  - `infra/docker-compose.prod.yml` and `infra/Dockerfile.server`;
  - systemd user units;
  - `scripts/backup` and `scripts/restore`, tested against dev;
  - `docs/PROD.md`;
  - `RisiMe.Release` for migrations inside a release.
- The test server now runs from a release-tag worktree, `~/risime-run/<tag>` (decision 006).

## Verification
- **Server gate:** 93 tests, 0 failures.
- **Android gate:** `assembleDebug testDebugUnitTest assembleRelease`, 72 tests, 0 failures.
- **Live interop:** the Android JVM clients against the server built from `main`.
  - REST, live delivery in 12 ms, delivered → read, idempotent resend, `empty_body`, offline
    catch-up in order, and AuthFailed on a bad token all pass.
  - v1.2: the presence snapshot, the online signal, typing true/false without moving the cursor,
    and offline after the 5 s grace (5019 ms) with `last_seen` all pass.
- Not yet run on a device: the UI, Room, and the release build install.

## Install
- On the laptop: `git pull && scripts/fetch-latest-apk --install`.
- **Once**, before the first release-signed install: `adb uninstall lk.codegen.risime` (this
  removes the debug-signed v0.1.0 build and its local data).

## Known limits
- No push; online means the app is open.
- Presence is in memory on one node.
- Message order is by local time.
- Not end-to-end encrypted.

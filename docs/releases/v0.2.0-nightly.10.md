# RisiMe v0.2.0-nightly.10 — encrypted groups

Wire protocol: `contract/v1/PROTOCOL.md` **v1.9**. Server: https://risime.risicloud.ai.
**Not a required update.** Older apps keep working for 1:1 chats. Only people on this version can be
added to groups.

## Install
In the app: Settings → Update. Or open **https://risicloud.ai/app/risime/** in your phone's browser,
tap **Download RisiMe** and install over the old app. Your chats and login are kept.

## New for users
- **Groups, end-to-end encrypted (MLS):**
  - **Creating a group:** chat list → **New group**, pick friends, give it a name. You become the
    admin.
  - **Admins:** add your own friends, remove members, rename the group, and make others admin.
  - **Leaving:** anyone can leave. The last admin first makes someone else admin.
  - **Keys:** removing someone rotates the group's keys, so they can't read anything new. New
    members don't see earlier messages.
  - **Group info:** tap the ⓘ icon (or the group picture) to see members and roles.
  - **"Read by":** long-press your message → **Info** to see who has received and read it.
  - **System lines** in the chat ("Kamal added Nimali", "… left", renames).
  - **Notifications** are grouped per group.
  - Up to 256 people per group.
- A friend shows as "needs to update" until they install this version.

## Not yet
- Group icons (come with encrypted images, next).
- Search doesn't include group messages yet, and there's no per-group mute.

## Verification
- Gates: server, Android (including group screen tests in dark mode on a small screen), crypto
  (including a 256-member group: create 65 ms, join 18 ms, decrypt 2.6 ms on spark2).
- Live interop on an isolated store: 11 group checks with the real MLS core (create, messages,
  Read by, rename, admin-only policy, add with no history, removal key rotation, leave, last admin,
  large commits by blob reference with hash checks, paged catch-up, legacy apps excluded), plus all
  1:1, E2EE and reaction checks.
- Blobs are backed up with the databases.

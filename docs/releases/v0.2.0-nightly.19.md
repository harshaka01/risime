# RisiMe v0.2.0-nightly.19 — hotfix: a chat that crashed when opened

Wire protocol: `contract/v1/PROTOCOL.md` v1.15. Server: https://risime.risicloud.ai. **Not a
required update.**

## Important: update, never uninstall
Always update **over** the old app. Never uninstall or clear the app's data.

## Fixed
- **Opening a chat crashed the app** (nightly.17/18) when a message was waiting to be sent in an
  encrypted chat. Sending it ran encryption work on the screen's thread, and Android stopped the
  app. All encryption work now runs in the background, and the waiting message is sent normally.
  Debug builds now flag any such main-thread work, and the release gate fails on it.

## Also inside (no visible change yet)
- Groundwork for history sharing (contract v1.15): a local index of messages this phone couldn't
  decrypt, and a database upgrade. The "Request history" feature comes in a later release.

## Verification
- Gates: server, Android, crypto.
- A unit test reproduces the crash (it fails without the fix).
- Live interop: all checks.
- Two real calls on Redroid with a message pending; the logcat gate shows no crash and no
  main-thread database work.
- **Automatic two-phone upgrade gate** (Redroid): the published nightly.18 is upgraded in place to
  this build (including the database upgrade). Messages, the device id, the group (both ways),
  photos, reactions and delete for everyone all still work.

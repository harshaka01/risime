# RisiMe v0.2.0-nightly.14 — 1:1 encryption switches on, per-chat lock, logout keeps chats, group ticks

Wire protocol: `contract/v1/PROTOCOL.md` v1.13 (calls are in the protocol; the app gets them in a
later release). Server: https://risime.risicloud.ai. **Not a required update.**

## Important: update, never uninstall
Always update over the old app (Settings → Update, or https://risicloud.ai/app/risime/ in your
phone's browser). Never uninstall.

## Fixed
- **1:1 encryption now switches on** for every pair on current builds:
  - Old or dead installs, from before a reinstall or an update, no longer block it.
  - The app retries by itself until the chat is encrypted.
  - If a chat isn't encrypted yet, the note says the real reason: "needs to update RisiMe", or
    "waiting for <name>'s phone to come online", or "<name>'s phone hasn't finished setting up
    encryption".
- **No more "Dev build — not end-to-end encrypted" banner** (decision 048). Encrypted chats show a
  🔒 in the header, and chat info says "Messages are end-to-end encrypted". Settings → About no
  longer says "MLS arrives in 0.3".
- **Log out keeps your chats** (decision 050):
  - Signing back in with the same account brings everything back, groups included, with nothing
    missing.
  - To remove them, use **Log out and delete chats from this phone** (it asks first).
  - Signing in with a different account asks before deleting the previous account's chats.
- **Group ticks:** ✓ → ✓✓ → read now updates. A receipt that arrived very quickly used to be lost.
  A message stays at ✓ while any member hasn't received it yet (for example a phone that's off).

## Also inside
- The app can now *receive* "delete for everyone" (the delete buttons come in a later release, once
  everyone has this version).

## Verification
- Gates: server, Android, crypto.
- Live interop:
  - a dead reinstall or an old install doesn't block 1:1 encryption;
  - ticks go ✓ → ✓✓ → read with a member offline first;
  - log out, receive messages while logged out, sign back in: old chats and group content are
    there, with no gap, and messages flow both ways.
- Automatic upgrade gate on spark2 (Redroid): the published nightly.13 is upgraded in place to
  this build, with messages kept, no sign-in, and new messages delivered.

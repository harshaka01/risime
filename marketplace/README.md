# Risi Marketplace registry (`risi_registry`)

The list of agents Risi may ask: signed agent cards, status, delisting, a content-free audit and a sandbox suite, plus
the signed-in marketplace page. A separate Phoenix app inside the RisiMe repo for now, built to be split out
(`docs/decisions/001-separable-registry.md`).

- Wire contract: `CONTRACT.md` (points to the RisiBridge contracts).
- Working rules and the test gate: `CLAUDE.md`.
- What's done and what's next: `STATUS.md`.
